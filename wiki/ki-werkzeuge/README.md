# KI-Werkzeuge

KI-gestützte Entwicklungswerkzeuge sind seit 2023 fester Bestandteil des Alltags vieler
Entwicklerinnen und Entwickler. Für einen Kurs über digitale Unabhängigkeit sind sie ein
besonders interessanter Fall: Sie sind produktiv und nützlich, gleichzeitig aber fast
ausnahmslos proprietär, cloudgebunden und in der Hand genau der Konzerne, von denen wir
uns in anderen Bereichen gerade unabhängig machen wollen.

Dieser Abschnitt sammelt Einordnungen zu einzelnen Werkzeugen. Der Maßstab ist dabei nicht
„Big Tech = schlecht", sondern die Leitfrage aus dem Kursmodul
[Digitale Unabhängigkeit](../../kurs/01-einstieg-open-source/01-digital-independence.md):

> Von welchen Abhängigkeiten ist Unabhängigkeit wirklich wichtig und welche nehme ich
> bewusst in Kauf?

## Wiederkehrende Fragen

Wenn du ein KI-Werkzeug bewertest, helfen dieselben Fragen wie bei jedem anderen Dienst:

| Frage | Warum sie zählt |
|---|---|
| Wo läuft das Modell? | Lokal = deine Daten bleiben bei dir. Cloud = dein Code verlässt den Rechner. |
| Ist der Client Open Source? | Bestimmt, ob du prüfen kannst, was das Werkzeug tatsächlich sendet. |
| Sind die Modellgewichte offen? | Entscheidet, ob du das Modell auch ohne den Anbieter weiterbetreiben kannst. |
| Wer haftet für den Output? | Lizenzfragen bei generiertem Code sind ungeklärt. |
| Was passiert bei Abschaltung? | Siehe [Lock-in](../glossar.md#lock-in--vendor-lock-in). |
